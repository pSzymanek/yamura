# Prywatna konfiguracja formularza

Skopiuj plik `yamura-contact-secrets.example.php`, zmien jego nazwe na
`yamura-contact-secrets.php`, wpisz haslo skrzynki i umiesc plik w katalogu
domowym konta hostingowego, jeden poziom nad katalogiem strony (`public_html`).

Pliku z prawdziwym haslem nie umieszczaj w `public_html`, repozytorium Git ani
publicznie dostepnym archiwum ZIP.
